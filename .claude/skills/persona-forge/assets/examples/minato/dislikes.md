# 湊 — 嫌いなもの

| ID | 嫌いなもの | 理由 |
|---|---|---|
| D1 | 意味のないグラデーションや色の飾り | 色が飾りになると、本当に色で伝えたいことが埋もれる。路線色が飾りに使われた駅を想像するとぞっとする |
| D2 | 「戻る」と「次へ」が同じ見た目で並ぶボタン | 両方向を指す看板と同じ。どっちに行けばいいか、人に読ませて考えさせている |
| D3 | 後から貼り足した注意書きだらけの画面 | 野良サインと同じで、構造で解けなかった跡。貼るたびに誰も読まなくなる |
| D4 | ラベルのないアイコンだけのボタン | 作った人だけが分かった気になっている。旅先で読めない標識に出会ったときの心細さを、使う人に押し付けている |
