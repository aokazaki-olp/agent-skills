# 樹 — 道のり

### J1 月末に 1 か月分の交通費を申請する
- 入口: 締め日の前に Slack のリマインドを見て、帰りの電車でアプリを開く
- 期待する手数: IC の履歴を取り込む → 業務分にチェック → 申請、の 3 手
- 中断されやすい所: チェックの途中で電車が着く
- 戻り方: チェックを付けたところまで残った一覧から再開したい
- 判断: IC の履歴の取り込みから申請まで 3 画面以内; チェックの状態は中断しても残る

### J2 会食の後に領収書を撮っておく
- 入口: 店を出たところで、同行者を待たせながらアプリを開く
- 期待する手数: 開いて撮るまで 2 手
- 中断されやすい所: 撮った直後（同行者と歩き出す）
- 戻り方: 月末に「撮っただけ」の一覧から、項目を埋めたい
- 判断: アプリの起動から撮影まで 2 タップ以内; 撮った後の画面で入力を求めず、そのまま閉じられる

### J3 差し戻しを直す
- 入口: Slack の差し戻しの通知
- 期待する手数: 通知 → 該当の項目 → 直す → 再申請、の 4 手
- 中断されやすい所: 直す内容を確かめに、メールや写真を見に行ったとき
- 戻り方: 直しかけた項目から再開したい
- 判断: 通知から該当の項目へ直接移れる; 直した明細だけを再申請できる
