# スクリプトの呼び方の書き方

SKILL.md の本文に書く形。種類 B の変数は、Claude Code が SKILL.md を読み込むときにスキルのディレクトリの絶対パスへ置き換える。このファイルは Read で読まれ、置き換えは起きない。

| | 種類 A（共通） | 種類 B（Claude Code 専用） |
|---|---|---|
| 本文での書き方 | `scripts/<名前>.mts`（スキルのルートからの相対パス） | `${CLAUDE_SKILL_DIR}/scripts/<名前>.mts` |
| 実行時の呼び方 | `node <このスキルのディレクトリ>/scripts/<名前>.mts <対象の絶対パス>` | `node "${CLAUDE_SKILL_DIR}/scripts/<名前>.mts" <対象の絶対パス>` |

どちらの種類でも、スキルのディレクトリを基準にしたパスで実行し、`cd` はしない。処理の対象は絶対パスで渡す。種類 A の本文には、この一文を添える。

種類 A の本文に変数を書かない。Claude Code ではコードの中でも置き換わり、ほかのエージェントでは置き換わらないので、どちらでも意図した形にならない。
